# @lupin/automation

The AI-gateway port and its Kilo and Ollama adapters, with streaming, served by the API at `/api/v1/chat/*`. An unconfigured installation answers a coded 503 rather than failing to start.

```bash
pnpm --filter @lupin/automation test
```

Part of the [Lupin](https://github.com/Sergey-Bar/Lupin) monorepo; see the root README for the whole picture.
