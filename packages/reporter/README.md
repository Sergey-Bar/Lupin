# @lupin/reporter

Producer adapters that read Playwright JSON, JUnit XML, k6 summaries, OWASP ZAP XML and legacy uploads into one canonical run result, including retries as `flaky`.

```bash
pnpm --filter @lupin/reporter test
```

Part of the [Lupin](https://github.com/Sergey-Bar/Lupin) monorepo; see the root README for the whole picture.
